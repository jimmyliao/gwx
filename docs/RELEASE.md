# Releasing gwx

Releases are built by [cargo-dist](https://github.com/axodotdev/cargo-dist) via
`.github/workflows/release.yml`, triggered by pushing a version tag.

## Cut a release

```sh
# from a clean main/master, bump version in Cargo.toml if needed, then:
git tag v0.1.0
git push origin v0.1.0
```

The tag push triggers the release workflow, which builds all target binaries, generates
the `gwx-installer.sh` shell installer + Homebrew formula + checksums, and attaches them to
a GitHub Release for that tag.

## The bundled OAuth client secret (required for a "just works" install)

gwx ships a **bundled Google OAuth client** so end users don't need their own GCP project
(see `src/main.rs`, `GWX_CLIENT_ID` / `GWX_CLIENT_SECRET`, and `docs/SPEC.md`).

- **`GWX_CLIENT_ID`** is public-safe and lives in source.
- **`GWX_CLIENT_SECRET`** is **not** in source. It is injected at **compile time** via
  `option_env!("GWX_CLIENT_SECRET")` and supplied as a **GitHub Actions repo secret**.

### One-time setup (repo owner)

1. Repo → **Settings → Secrets and variables → Actions → New repository secret**
2. Name `GWX_CLIENT_SECRET`, value = the OAuth client's secret.

The release workflow's build job passes it through as a build env var (see the `env:` block
in `release.yml`). A binary built **without** this secret set falls back to BYO-client / a
"not configured" message — fine for dev builds, but such a release won't have the bundled
client.

> ⚠️ **cargo-dist caveat:** `release.yml` is generated by `dist generate`. If you regenerate
> it, **re-add** the `GWX_CLIENT_SECRET: ${{ secrets.GWX_CLIENT_SECRET }}` line to the build
> job's `env:` block.

## Install URL

cargo-dist's installer is a **release asset**, not a file on `main`. The install command is:

```sh
curl -fsSL https://github.com/jimmyliao/gwx/releases/latest/download/gwx-installer.sh | sh
```

(Not `raw.githubusercontent.com/.../main/install.sh` — update the README to the releases URL
before announcing.)

## Two publishes to reach the public

A public "curl-install → auth → works" flow needs **both**:

1. **This GitHub release** (binaries + installer) — above.
2. **Google OAuth app publish/verification** — the bundled client's Google app must be
   published (removes the 7-day test-token expiry) and, for unlimited users without the
   "unverified app" warning, **verified** (restricted-scope CASA assessment). See `docs/SPEC.md`.
   Until then: bundled client works for up to 100 lifetime users (with a warning); power users
   can bring their own client (BYO) for unlimited use with no verification.
